# Pry.it — инструкция простыми словами

Pry.it — Telegram-каталог цифровых проектов для украинского бизнеса. Заказчик публикует проект, фрилансеры присылают предложения, заказчик выбирает исполнителя, а после завершения обе стороны могут оставить отзыв.

## Важно про деньги

Сейчас бот **не принимает и не хранит деньги**. Оплату и условия стороны согласуют между собой. Не называйте Pry.it эскроу, гарантом или безопасной оплатой: этих функций пока нет.

## Первый запуск

### 1. Обновите существующую базу Supabase

1. Откройте сайт Supabase и войдите в свой проект.
2. В левом меню нажмите **SQL Editor**.
3. Нажмите **New query**.
4. На компьютере откройте файл `supabase/setup.sql` из папки Pry.it.
5. Скопируйте весь текст файла, вставьте его в окно запроса Supabase и нажмите **Run**.

Скрипт подходит к базе, которая сейчас подключена к боту: проекты в ней имеют числовые ID. Он сохраняет старые проекты и добавляет нужные поля. Из-за отсутствия срока у старых проектов незавершённым будет назначен срок через 30 дней; их нужно проверить перед продолжением работы.

Для старых проектов с назначенным исполнителем скрипт создаст техническую запись, чтобы новый сценарий сдачи работы мог продолжиться. Это не настоящий отклик и не сохранённый файл. Два старых проекта со статусом «на проверке» не имеют сохранённых файлов результата; заказчику нужно будет попросить исполнителя отправить их ещё раз. Два старых завершённых проекта не сопоставились с аккаунтами заказчиков; их исходные записи сохраняются в базе, но в профиле заказчика они не появятся.

Если Supabase покажет ошибку, остановитесь: **не удаляйте таблицы и не запускайте старые SQL-коды**. Пришлите скриншот ошибки — я подскажу следующий шаг.

### 2. Проверьте настройки бота

В папке Pry.it должен быть файл `.env`. В нём нужны четыре значения:

- `TELEGRAM_BOT_TOKEN` — токен из BotFather.
- `SUPABASE_URL` — адрес проекта Supabase.
- `SUPABASE_SERVICE_ROLE_KEY` — секретный ключ Supabase для серверного приложения.
- `ADMIN_TELEGRAM_ID` — ваш числовой Telegram ID.

Рядом есть `.env.example` — это только образец. Вставлять настоящие ключи нужно в `.env`. **Не отправляйте мне и никому другому содержимое `.env` и не публикуйте этот файл.**

Чтобы бот мог присылать вам уведомления об очереди модерации, откройте бота в Telegram и нажмите **Start** под аккаунтом администратора.

### 3. Включите бота

Откройте папку Pry.it, запустите в ней терминал и введите:

```text
npm start
```

Пока это тестовый запуск на вашем компьютере: если закрыть окно терминала или выключить компьютер, бот остановится. Для круглосуточной работы его позже нужно разместить на постоянно работающем сервере. Если бот не запустился, пришлите скриншот сообщения об ошибке, предварительно закрыв или замазав токены и ключи.

## Как пользоваться

1. Заказчик заполняет карточку: название, категорию, описание, бюджет, валюту и срок.
2. Проект попадает администратору на проверку.
3. После публикации фрилансеры присылают предложение, свою цену и необязательную ссылку на портфолио.
4. Заказчик выбирает одного исполнителя и связывается с ним в Telegram.
5. Исполнитель присылает ссылку на результат; заказчик принимает работу или просит доработку.
6. После завершения участники могут оставить друг другу оценку и отзыв.

Если бот перезапустится, незаконченная анкета сбросится; уже сохранённые проекты и отклики останутся в Supabase.

## Как развивать проект

Не стоит начинать с обещания «фриланс-биржа для всех». Для первого запуска лучше найти небольшую группу украинских заказчиков с реальными задачами в нескольких цифровых направлениях — дизайн, видео, разработка и автоматизация — и лично помочь им разместить первые качественные проекты. Без настоящих заказов, отзывов, поддержки и доверия одной доработки кода недостаточно, чтобы сделать площадку популярной.

## Круглосуточный запуск через Render

В папке уже подготовлен файл `render.yaml` для размещения бота на Render. Он задаёт запуск Node.js, проверку `/health`, регион Frankfurt и постоянно работающий план.

Файл сам по себе ничего не запускает и не списывает деньги. Бесплатные веб-сервисы Render засыпают при отсутствии входящих запросов, поэтому для постоянно работающего бота нужен платный план. На момент подготовки настройки минимальный подходящий план указан как `0.5c-512mb`; перед запуском проверьте цену на экране Render. По опубликованной Render информации, такой уровень ранее стоил около 7 долларов США в месяц.

Для запуска потребуется подключить GitHub-репозиторий к Render. Эта папка пока не связана с GitHub, поэтому бот ещё не размещён в облаке. При создании сервиса Render попросит добавить `TELEGRAM_BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` и `ADMIN_TELEGRAM_ID`. Их нужно ввести непосредственно в Render; файл `.env` в GitHub не загружать.
